# AI Search Algorithms

This project compares five search algorithms for a weighted route-finding problem.

## Algorithms
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Uniform-Cost Search (UCS)
- A* Search
- Greedy Best-First Search (GBFS)

## Experiments
- Comparison of algorithm performance on the original graph.
- Evaluation using a modified, non-admissible heuristic.
- Testing on a larger graph.

## Files
- `route_search.py` — Python implementation of all five algorithms.
- `Screenshots/` — Screenshots of implementation, outputs, and experiments.
